# אליאס 🎲

משחק הסברת מילים קבוצתי בעברית. כל שחקן מתחבר מהטלפון שלו דרך קישור לחדר, עם טיימר משותף לכולם.

- `index.html` - המשחק (מסונכרן בזמן אמת דרך Firebase Realtime Database)
- `words.js` - מאגר המילים לפי רמות קושי
- `database.rules.json` - כללי אבטחה למסד הנתונים (להדביק בלשונית Rules ב-Firebase)
